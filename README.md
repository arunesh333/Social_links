# Arunesh E – Social Links Profile Website

A simple and responsive social media profile webpage made with **HTML5** and **CSS3**, featuring links to my GitHub, LinkedIn, X (Twitter), and Instagram accounts.

Inspired by [Frontend Mentor](https://www.frontendmentor.io/) challenge.

---

## 🚀 Features

- Clean personal branding layout
- Profile image with name and location
- Description and social media links
- Image icons with hover effects
- Fully responsive and minimalist

---

## 🌐 Live Demo

🔗 [Click to View Live](https://arunesh333.github.io/Social_links/)  

---

## 📌 Notes

- No frameworks or libraries used — just pure HTML and CSS.
- All icons are PNGs — no external CDNs or fonts used.
- Mobile responsiveness is handled through `viewport` and `flexbox`.
